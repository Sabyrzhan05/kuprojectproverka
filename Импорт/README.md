# Импорт показаний — папки по месяцам

Файлы поставщиков кладутся сюда как есть, по одному месяцу в папку:

```
Импорт/
  2026/
    07/   ← файлы за июль 2026: выгрузка АРЭК, отчёт Су-Арнасы, ЭСФ Теплотранзита
    08/
```

Имена файлов любые — тип определяется по содержимому:

| Поставщик | Файл | Что берётся |
|---|---|---|
| АРЭК (электро) | «Апартаменты ДД.ММ.ГГ.xlsx» — один снимок показаний на дату | конец периода по серийнику. Начало — из более раннего снимка АРЭК в той же папке, если положить два; иначе конец предыдущего месяца в стенде |
| Су-Арнасы (вода) | `water_meters_consumption_report_by_all_objects_<с>_<по>.xlsx` | ХВС и ГВС по серийнику: начало и конец |
| Теплотранзит (тепло) | ЭСФ `.xls` / `.xlsx` | сумма Гкал по строкам «Тепловая энергия» → поле «Тепло, Гкал по ЭСФ» этого месяца; на помещения делится расчётом по площади, разграниченные по теплу платят поставщику сами |

В стенде: выбрать период → кнопка **«Импорт показаний»** → окно показывает, что в папке, что
сопоставилось (по серийному номеру), что нет, что перезапишется → **«Импортировать»**.
Перед записью сервер делает копию базы (`data/backup/…_pre-import-ГГГГ-ММ`), откат —
кнопкой «Вернуть копию». Показания, зафиксированные актом замены прибора, импорт не трогает.

Нужен Python 3 с `openpyxl` и `xlrd` (`python -m pip install openpyxl xlrd`) — файлы читает
`server/parse_import.py`, сопоставление и запись делает `server/import.js`.

Папка `2026/07` — реальные июльские файлы (22.06→23.07 АРЭК, 24.06→25.07 Су-Арнасы, ЭСФ за июль),
по ним стенд и был заполнен; повторный импорт ничего не меняет.
